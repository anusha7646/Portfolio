# Anusha Ravi Portfolio

An accessible, responsive personal portfolio for Anusha Ravi, a fresher Front-End Developer.

## Structure

```text
website/
├── index.html
├── assets/
│   ├── Anusha_Ravi_Resume.pdf (add your PDF here)
│   ├── images/
│   └── icons/
├── pages/
│   └── solace.html
├── css/
│   ├── style.css
│   ├── responsive.css
│   └── solace.css
├── js/
│   ├── script.js
│   └── solace.js
└── README.md
```

## Run locally

Open `index.html` in a browser or use a static development server. The resume buttons already point to `assets/Anusha_Ravi_Resume.pdf`; add the real PDF to that path when ready. The additional `pages/solace.html` page is retained as the earlier alternate concept.

## How it works

- `index.html`, `css/style.css`, `css/responsive.css`, and `js/script.js` make up Anusha Ravi's portfolio.
- `pages/solace.html`, `css/solace.css`, and `js/solace.js` make up Solace House, a coastal hotel experience.
- The portfolio contact form validates on the client and clearly does not pretend to send a backend email.
